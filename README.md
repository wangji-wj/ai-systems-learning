# AI Systems Learning

一个面向 **AI 底层算法与系统实现** 的学习仓库。这里不仅记录概念，也强调从数学原理、模型结构到 PyTorch、C++/CUDA 和大模型推理系统的动手实现。

## 学习目标

- 补齐线性代数、微积分和概率论等数学基础。
- 从零实现并理解常见深度学习结构。
- 掌握 PyTorch 自动求导、训练流程和性能分析。
- 理解 SFT、LoRA、DPO 等大模型微调方法。
- 建立 C++、Linux、多线程和 CUDA 编程能力。
- 分析并实践 KV Cache、连续批处理等 LLM 推理优化技术。

## 建议的内容格式

每个主题尽量包含以下内容：

1. `README.md`：问题背景、核心原理、公式与结论。
2. 可运行代码：从最小实现开始，再逐步优化。
3. 测试或数值校验：验证正确性，并注明误差范围。
4. Benchmark：记录硬件、软件版本、输入规模、预热方式和结果。
5. 学习总结：记录踩坑点、性能瓶颈和后续问题。

数学公式使用 LaTeX，代码优先保证可复现。大文件、数据集、模型权重和实验输出不提交到 Git；必要时在文档中提供获取方式。

## 学习路线

建议按目录编号推进。数学与深度学习部分可以交叉学习；进入 CUDA 和推理优化前，建议先完成 PyTorch、C++ 与 Linux 的核心内容。

## 环境说明

项目会逐步包含 Python、PyTorch、C++ 和 CUDA 示例。各主题的依赖与运行命令应写在对应目录的 `README.md` 中，避免根目录环境随内容增长而过度耦合。

## 贡献约定

- 一个提交聚焦一个明确主题。
- 提交信息建议使用 `docs:`、`feat:`、`fix:`、`perf:`、`test:` 等前缀。
- 新增实验时同时补充运行方法与关键结果。
- 不提交密钥、个人配置、模型权重、数据集或生成产物。
