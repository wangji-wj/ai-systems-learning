# Repository Guidelines

## Scope

This repository records hands-on study of low-level AI algorithms and systems. Keep explanations connected to executable implementations, numerical checks, or reproducible benchmarks.

## Working conventions

- Read `.agents/skills/ai-systems-learning/SKILL.md` before adding or reorganizing learning content.
- Put content in the narrowest matching numbered topic directory.
- Keep each example small and independently runnable before adding optimized variants.
- Explain non-obvious formulas, tensor shapes, memory layouts, and performance assumptions.
- Add tests or reference comparisons for algorithmic and kernel implementations.
- Record hardware, software versions, input shapes, warm-up, and measurement method for benchmarks.
- Do not commit credentials, local IDE state, datasets, model weights, checkpoints, or generated outputs.
- Preserve unrelated work in the repository and avoid broad mechanical rewrites.

## Documentation

Use Markdown and LaTeX for notes. A topic README should normally cover motivation, derivation, implementation, verification, results, pitfalls, and references. Prefer links to primary sources such as papers and official documentation.
